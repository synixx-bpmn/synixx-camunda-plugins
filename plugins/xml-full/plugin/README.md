# BPMN-XML-Vollansicht (Camunda Modeler Plugin)

Zeigt das **komplette BPMN-XML des geöffneten Modells als einklappbaren
Baum** in einem schwebenden Fenster — Sektionen auf-/zuklappbar, zum
Verstehen der Modellstruktur und zum Prüfen, was der Modeler wirklich
ins XML schreibt.

## Verwendung

- Pill **„XML"** in der Werkzeug-Leiste — oder **Alt+Shift+M**.
- Die Ansicht folgt dem Modellstand; erneuter Klick schließt.

## Installation

1. Diesen Ordner (`cm-plugin_xml-full`) in das Plugin-Verzeichnis von Camunda
   Modeler kopieren:
   - **macOS / Linux**: `~/.camunda-modeler/plugins/cm-plugin_xml-full/`
   - **Windows**: `%APPDATA%\camunda-modeler\plugins\cm-plugin_xml-full\`
2. Camunda Modeler neu starten.

Alternativ: in eine Modeler-Instanz unter `<modeler>/resources/plugins/`
ablegen — dann nur in dieser Instanz aktiv. Kompatibel mit Camunda Modeler 5+.
