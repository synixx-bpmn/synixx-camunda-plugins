# BPMN-Notationsübersicht (Camunda Modeler Plugin)

Blendet eine durchsuchbare **BPMN-Notationsübersicht** (Symbol-Legende mit
Kurzbeschreibungen) als schwebendes Fenster über dem Diagramm ein — zum
Nachschlagen während des Modellierens, ohne den Modeler zu verlassen.

## Verwendung

- Pill **„BPMN"** in der Werkzeug-Leiste oben rechts im Canvas — oder
  Tastatur-Shortcut **Alt+Shift+B**.
- Das Fenster ist ziehbar und bleibt offen, während man weitermodelliert;
  erneuter Klick schließt es.

## Installation

1. Diesen Ordner (`cm-plugin_notation`) in das Plugin-Verzeichnis von Camunda
   Modeler kopieren:
   - **macOS / Linux**: `~/.camunda-modeler/plugins/cm-plugin_notation/`
   - **Windows**: `%APPDATA%\camunda-modeler\plugins\cm-plugin_notation\`
2. Camunda Modeler neu starten.

Alternativ: in eine Modeler-Instanz unter `<modeler>/resources/plugins/`
ablegen — dann nur in dieser Instanz aktiv. Kompatibel mit Camunda Modeler 5+.
